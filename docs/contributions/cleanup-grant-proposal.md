# 独立设计草稿：测试数据清理授权

## 状态

本功能保留在 fork 的集成分支，不包含在三个候选贡献分支中。
目前它针对测试搜索历史清理和单条恢复流程，尚未确认应成为上游通用接口。

## 讨论范围

- 是否需要任务级预授权，还是继续要求每次后果操作原生确认。
- 谁能签发授权、如何证明用户同意、怎样绑定任务、设备、测试数据及期限。
- 重复执行、取消、跨进程重启、恢复授权及授权撤销的语义。
- 如何让设备适配与具体业务页面结构解耦，并证明不删除用户原有数据。
- 哪些行为应始终要求逐次确认，以及如何独立审查和复现实验。

现有实现的摘要绑定、持久消费、数量限制与恢复证明可作为讨论输入，不能仅凭
已有单测就视为通用授权设计获认可。维护者确认方向前不随鸿蒙 PR 一起投稿。
