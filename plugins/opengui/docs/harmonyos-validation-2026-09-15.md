## 真机链路

设备型号 `TYR-AL00`，系统 API 24，HDC `3.2.0d`，UiTest `6.0.2.3`。测试应用使用设备上已有的 Flutter Beta 1.1.7（18）安装包，没有升级应用。

通过**编译后的公开 CLI**创建会话并执行：

1. 设备发现、授权状态和 `--doctor` 检查成功。
2. 观察桌面，使用 bundle + UIAbility 启动应用。
3. 查看截图并点击搜索入口。
4. 输入 `鸿蒙驱动验证🙂`，驱动返回 `permission_required`。
5. 在已有测试授权范围内选择“本次使用允许”，确认输入框文本完全一致。
6. 长按输入框，确认剪切/复制/粘贴/全选四个按钮出现。
7. 清空输入、收起键盘、移除本次生成的搜索记录并返回首页。
8. 上滑列表并下滑恢复；Home 返回桌面。
9. 设备预览接口返回 HTTP 200、`image/jpeg`；未另行验证浏览器界面。
10. 关闭会话，确认该会话的运行时截图已删除。

首个会话共完成 13 次观察/操作。另建会话验证：过期 observation 被拒绝、失败后旧凭据不可重用、重新观察可恢复操作；进行中的 10 秒等待被取消，取消调用约 0.102 秒完成，会话截图随之清理。

最终 CLI 构建完成后重新启动守护进程，再次验证真机稳定观察、会话关闭及守护进程退出。
