## 10 轮基线结果

每轮均由一个新的 Codex AI 会话接收自然语言任务，创建独立 OpenGUI 控制会话，根据实际截图逐步决定动作。没有用固定坐标脚本替代 AI 决策；应用保持登录，不在每轮强制冷启动。

流程：观察 → 启动应用 → 打开搜索 → 输入本轮唯一中文/数字/Emoji → 核对完整文本 → 清空输入 → 移除本轮本地搜索记录 → 返回首页 → 保存证据 → 关闭会话。

每轮六项断言为 `search_opened`、`text_exact`、`input_cleared`、`history_removed`、`returned_home`、`session_closed`。

## 修补与额外复验

新增 `--compact`：保留最新 observationId、截图路径、布局稳定性、聚焦输入框和授权状态，完整观察 JSON 写入私有 `observationPath`；会话关闭时 JPEG 和 JSON 一并清理。补充了等待原命令完成、避免解析截断终端文本的技能指引。协议升级为 3，升级前结束旧会话和旧守护进程。

修补后 `pnpm check` 通过：**97 个测试、TypeScript 检查、CLI 构建与插件暂存校验**；技能格式校验通过。默认完整输出仍保留。

刷新插件后，新 AI 会话额外执行一次完整流程：结果 **PASS**，8 次观察/动作，0 次设备操作恢复，耗时 **8 分 2.6 秒**。该次另行验证完整 JSON 可以读取、必要证据在关闭前复制、原运行时 JSON 随会话清理。此补充样本不混入上述 10 轮统计，也不作为性能提升比例的依据。

独立复核确认，8 个 `--compact` 观察/动作响应都能完整解析为 JSON，最大 1859 字节。辅助读取完整布局时，AI 首次筛选范围过宽，仍产生过一次终端截断；改为精确筛选后继续，未追加设备观察/动作。完整 JSON 应按需要查询字段，不能任意整份输出到有限长度的终端。
